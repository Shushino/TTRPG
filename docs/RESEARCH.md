# RESEARCH.md — TTRPG genre research toward the ruleset decision (Q1)

**Purpose:** George (~6 months of research/playing, target ≈ **March 2027**) and the coursemates are deciding what TTRPG system this app should serve first. Every system played or read gets logged here — this file is what the ruleset vote will be argued from, and it's part of the AI-session context pack (PLAN §11), so feed it along with PLAN/DEVLOG.

Nothing here costs money: every system below has a free, legal entry point (SRD, quickstart, or free core rules).

## How to log a system (copy this block per entry, newest at top of the Log)

```md
## <System name> — <date>, with <who>
- How far we got: quickstart only / one-shot / multi-session
- What clicked: ...
- What annoyed us: ...
- Character sheet highlights: (fields it actually uses — HP? spell slots? stress? conditions? inventory?)
- Dice: (notation, and how the roll resolution *felt* at the table)
- GM workload: (easy to improvise? prep-heavy?)
- Group reaction: (who liked what — this is the vote data)
- Verdict lean: (would we run THIS on the app first? why / why not?)
```

## Candidate list to try
- **D&D 5e** (2014 or 2024 rules) — the current placeholder; huge player base, free Basic Rules. Even if you don't pick it, it's the vocabulary everyone knows.
- **Pathfinder 2e** — the crunchy 5e alternative; fully free official SRD (Archives of Nethys).
- **Cairn / Mausritter (OSR)** — tiny rule sets, free PDFs; shows how *little* a game actually needs. Great calibration for "MVP".
- **Blades in the Dark / other Powered-by-the-Apocalypse games** — narrative-first; stress/position mechanics instead of HP grinding; very different sheet shape.
- **Fate Core/Condensed** — free SRD, generic system; aspects and fate points instead of ability scores.
- **Homebrew** — the reason the sheet template is a data file, not hard-coded UI.
